# Templates

Several templates for use with PHP-Bootstrap

## Template structure

```text
templates/
└── [template-name] []
    ├── layout
    │   ├── *.(php|html)
    │   └── js
    │       └── *.(php/js)
    └── assets
        ├── css
        │   └── *.(css)
        ├── img
        │   └── *.(png|jpg|svg|*)
        └── js
            └── *.(js)
```
