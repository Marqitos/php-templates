## Templates structure

```text
templates/
└── [template-name] []
    ├── layout
    │   ├── *.(php|html)
    │   └── js
    │       └── *.(php/js)
    ├── assets
    │   ├── css
    │   │   └── *.(css)
    │   ├── img
    │   │   └── *.(png|jpg|svg|*)
    │   └── js
    │       └── *.(js)
    └── README.md
```
